# Deewanji Reader

Offline phone reader for Deewanji project files (`.deewanji.json`, and older `.recap.json`). Open https://shilparts.github.io/Recap-reader/reader/ in Chrome on Android and choose **Add to Home screen**.

This page contains only the reader's code. Project files you add stay in the phone's own browser storage and are never uploaded. The reader code is published from the Deewanji desktop app (formerly called Recap); `handoff.js` and `project-transfer.js` are copied from it unchanged.
